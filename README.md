# Магазин авторских изделий — инструкция по запуску

Сайт — статический HTML/CSS/JS, подходит для GitHub Pages. Для безопасной отправки заявок в Telegram используется Cloudflare Worker: токен бота хранится только в секретах Worker, а не в браузере.

## 1. Опубликовать сайт на GitHub Pages

1. Скачайте и распакуйте архив.
2. Откройте репозиторий `https://github.com/wepoftus-star/my-store`.
3. Сделайте резервную копию текущих файлов, если они нужны.
4. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `script.js` (папку `telegram-worker` и README тоже можно оставить).
5. В GitHub откройте **Settings → Pages** и убедитесь, что публикация идёт из нужной ветки и корня (`/root`).
6. После сохранения сайт обычно обновляется через несколько минут по адресу:
   `https://wepoftus-star.github.io/my-store/`

Важно: это заменит текущую главную страницу Tile Reels Finder, если использовать тот же репозиторий. Если хотите сохранить старый сайт, создайте отдельный репозиторий для магазина.

## 2. Создать Telegram-бота

1. В Telegram найдите официальный аккаунт `@BotFather`.
2. Отправьте `/newbot`, задайте имя и username.
3. Скопируйте выданный токен. Не публикуйте его и не вставляйте в `script.js`.
4. Откройте своего нового бота и нажмите **Start** (или отправьте `/start`).

## 3. Узнать Telegram Chat ID

Самый простой вариант для личных заявок:
1. Напишите вашему новому боту `/start`.
2. В браузере откройте `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`, заменив `ВАШ_ТОКЕН` своим токеном.
3. Найдите `"chat":{"id":123456789,...}` — число и есть Chat ID.
4. Не отправляйте ссылку с токеном другим людям. После настройки закройте её.

Для группы: добавьте бота в группу, напишите там сообщение и посмотрите `chat.id` в `getUpdates` (у групп ID обычно отрицательный).

## 4. Развернуть защищённый Telegram endpoint на Cloudflare Workers

1. Создайте/войдите в аккаунт Cloudflare.
2. Откройте **Workers & Pages → Create → Worker** и создайте Worker с именем, например `my-store-order-bot`.
3. В редакторе замените код Worker кодом из `telegram-worker/worker.js`. Либо разверните через Wrangler из папки `telegram-worker`.
4. В настройках Worker → **Settings → Variables and Secrets** добавьте два значения именно как **Secrets**:
   - `TELEGRAM_BOT_TOKEN` = токен BotFather
   - `TELEGRAM_CHAT_ID` = ваш chat ID
5. Нажмите Deploy. Скопируйте URL Worker, например `https://my-store-order-bot.<ваш-субдомен>.workers.dev`.
6. В `script.js` замените строку:
   `const WORKER_URL = "PASTE_YOUR_CLOUDFLARE_WORKER_URL_HERE";`
   на URL своего Worker.
7. Сохраните `script.js` в GitHub и дождитесь публикации сайта.

Worker разрешает запросы только с `https://wepoftus-star.github.io`. Если вы подключите собственный домен, поменяйте `ALLOWED_ORIGIN` в `telegram-worker/worker.js` на точный origin домена (без пути и завершающего `/`).

## 5. Проверить заявку

1. Откройте опубликованный сайт.
2. Добавьте изделие в заказ, заполните имя и контакт, поставьте галочку согласия.
3. Нажмите отправку.
4. Убедитесь, что сообщение пришло в Telegram.

## 6. Добавить свои цены и реальные фотографии

В демонстрационном дизайне цены намеренно указаны как «Цена по запросу», а изображения изделий сделаны CSS-иллюстрациями, а не фотографиями ваших реальных изделий. Перед публикацией:
- замените текст цен в карточках `index.html`;
- замените декоративные блоки `.product-visual` на `<img src="images/имя-файла.jpg" alt="...">`;
- добавьте фотографии в папку `images` и загрузите её в корень репозитория.

Не заявляйте, что заявка отправлена, пока Worker не развернут и не проверен. Не добавляйте токен Telegram в HTML/JS: все посетители смогут его увидеть.

## Что включено

- Адаптивный каталог на русском языке.
- Фильтры категорий.
- Добавление и удаление позиций из заказа.
- Форма имени, контакта, email, комментария и согласия.
- Отправка заявки через Cloudflare Worker в Telegram.
- CORS-проверка источника и хранение Telegram-секретов вне публичного сайта.

## Перед реальным запуском

Проверьте, что текст согласия соответствует требованиям, применимым к вашему месту ведения бизнеса, добавьте актуальные условия обработки персональных данных и контакты продавца. Включите лимиты/защиту от спама в Cloudflare при необходимости.


Админ-панель и синхронизация каталога: см. `README-ADMIN.md`. Перед запуском обязательно настройте Supabase в `supabase-config.js` и Telegram Worker URL в `script.js`.


## Структура страниц (многостраничная версия)

- `index.html` — главная, `catalog.html` — каталог (фильтр работает и по ссылке `catalog.html?cat=mount|print|custom`),
  `product.html?id=…` — отдельная страница каждого изделия, `about.html` — о мастерской, `order.html` — заказ.
- Корзина хранится в браузере и сохраняется при переходах между страницами.
- Загрузите в корень репозитория все `*.html`, `styles.css`, `script.js`. `WORKER_URL` по-прежнему задаётся в `script.js`.

## Регистрация, история заказов и корзина (аккаунты)

Новое: `account.html` (вход, регистрация, сброс пароля, история заказов); корзина вошедшего пользователя синхронизируется между устройствами.

База данных уже настроена (таблицы `orders` и `carts`, права по пользователям; редактировать товары могут только администраторы из `store_admins`).
Файл `supabase-accounts.sql` оставлен для справки.

Осталось сделать вручную в Supabase → Authentication:
1. URL Configuration: Site URL — адрес вашего сайта; в Redirect URLs добавьте адрес страницы `account.html`.
2. Sign In / Providers → Email: регистрация новых пользователей включена; подтверждение почты рекомендуется оставить включённым.
3. Загрузите на сайт все `*.html`, `styles.css`, `script.js`, `admin.js`.
